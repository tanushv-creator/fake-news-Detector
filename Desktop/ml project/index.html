ML Pipeline

🌐
Data Fetch
WELFake dataset pulled from web — 72k real & fake articles
🧹
Preprocess
Lowercase, remove URLs, stopwords, stemming via NLTK
📊
TF-IDF
50k features, unigrams + bigrams, sublinear normalization
🌲
Random Forest
200 trees, balanced class weights, all CPU cores
🎯
Predict
Credibility score 0–100 with real/fake probability
